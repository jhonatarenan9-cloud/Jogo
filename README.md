# ⛏️ Mina Idle

Jogo idle de mineração em 3D no navegador. Abra o `index.html` para jogar (precisa de internet para carregar a biblioteca 3D three.js).

## Como jogar
- Arraste o dedo na tela (joystick) ou use WASD/setas para andar com o mineiro pelo mapa.
- Pare perto das pedras de uma mina aberta: o mineiro golpeia sozinho e o minério cai na pilha ao lado.
- Pise no quadrado **💰 VENDER** do Mercado para vender tudo, ou no **🛠️ LOJA** para abrir a loja.
- Cada mina fechada tem um quadrado com o preço da ferramenta na frente do portão. Fique em cima dele para ir pagando; quando completar, o portão abre.
- São 5 níveis, cada um exige uma ferramenta:
  1. Cobre — Picareta de Madeira (inicial)
  2. Ferro — Picareta de Ferro
  3. Ouro — Britadeira
  4. Diamante — Máquina Carregadeira
  5. Esmeralda — Escavadeira Gigante
- Ajudantes (mineiros, carrinhos, caminhões, esteiras, robôs) produzem sozinhos na última mina em que você minerou.
- Melhorias: afiar ferramenta, manutenção e gerente de vendas (venda automática).
- O progresso é salvo no navegador, e você ganha minério mesmo offline (50%, até 8h).
- Objetivo final: minerar 1.000 esmeraldas e virar Magnata da Mineração.
